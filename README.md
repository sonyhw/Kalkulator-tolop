# Kalkulator-tolop

Kalkulator toleransi operasi — evaluasi kardiovaskular perioperatif untuk bedah nonkardiak (AHA/ACC).

## Kalkulator RCRI (`index.html`)

- 6 komponen Revised Cardiac Risk Index (1 poin per item)
- Kategori risiko: rendah (RCRI ≤1) atau elevasi (RCRI >1; 2a, B-NR)
- Estimasi MACE per skor: Lee 1999 dan Duceppe 2017 (CCS)
- Daftar risk modifier dan rekomendasi langkah berikutnya
- Ringkasan yang bisa disalin ke rekam medis

File HTML tunggal tanpa dependensi; buka langsung di browser atau aktifkan GitHub Pages (Settings → Pages → branch `main`, folder `/root`).

Alat bantu keputusan klinis; tidak menggantikan penilaian klinis.
